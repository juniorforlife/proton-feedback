# Proton Product Feedback

A collection of bugs, feature requests, and other issues observed across Proton products.

## Issues

All bug reports and feature requests are tracked using [GitHub Issues](../../issues).

### Issue types

- 🐞 **Bug** — Something is not working as expected.
- 💡 **Feature** — A proposed new feature or capability.
- ⚡ **Performance** — A performance or responsiveness issue.

## Purpose

This is independent, individual work created by a privacy enthusiast and supporter of Proton. The reports are intended to document issues, provide constructive feedback, and contribute to the broader privacy community.

This repository is not affiliated with, sponsored by, endorsed by, or paid for by Proton. The author is an independent individual and does not represent Proton or its employees.
